"# LOST-ON-MARS-Project" 

This project was created in the open source game engine Godot for the NASA Space Apps Challenge. The game was made in godot in 7.2 hours by the NASA Space Apps Challenge team Ronesans Uzaylilari. 

To download the project, you must go to the releases section on this repository, then download the .exe file. The game can ONLY run on Windows operating systems. The game WILL NOT run on iPhones, iPads, Android Phones, Linux distributions etc. IT WILL ONLY RUN ON WINDOWS.

## How to Download & Play

1. Go to the **Releases** section on the right side of this repository.
2. Download the `.exe` file.
3. Run the executable to launch the game.

### Windows SmartScreen Warning

In case Windows SmartScreen blocks the game from launching (this happens because indie `.exe` builds do not have a paid Microsoft signing certificate), follow these steps to bypass it:

1. When the blue **"Windows protected your PC"** window pops up, click **More info** right below the warning text.
2. Click the **Run anyway** button that appears at the bottom of the window.
